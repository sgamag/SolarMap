CONEXIÓN Y PREPARACIÓN DE FUENTES COPERNICUS

objetivo: dejar lista la autentificación y las pruebas básicas de consulta
en Copernicus para datos tabulares.

pasos realizados:
1 validación de credenciales
Se creó login.py para obtener y cachear el token. Se verificó con testlogin.py

2 URL de servicio
Se documentó el endpoint de token y los endpoints de STAC para búsquedas

3 diseño de interfaz
Se definió el flujo básico de peticiones y cómo se mostrarán resultados 
(miniaturas y CSV)

4 recopilación de datos de referencia
Se revisó la documentación de ERA5 y STAC y se dejaron scripts de prueba para 
confirmar acceso

salidas
token obtenido y cacheado en token_cdse.json
script ver_imagen_stac.py validando búsquedas y miniaturas
lista de endpoints y parámetros clave

se puede autenticar, consultar y descargar datos de Copernicus para tablas 
sin errores

STAC: catálogo estándar en la web para buscar imágenes satelitales. De las un 
polígono y fechas y te devuelve la lista de escenas
