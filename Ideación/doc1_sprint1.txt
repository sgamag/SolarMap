ARQUITECTURA Y BASE TÉCNICA
En este sprint se establecieron los cimientos técnicos del proyecto. 
Se configuró el acceso a servicios externos mediante autenticación por credenciales, 
gestionando correctamente los headers necesarios para realizar peticiones a la API 
de Copernicus. Esta lógica queda reflejada en los primeros módulos de conexión y 
control de acceso.

Se definieron las URLs de acceso a los servicios de Copernicus y se realizaron 
pruebas de conectividad para validar la disponibilidad de datos y los formatos de 
respuesta. Esta fase permitió identificar limitaciones técnicas y requisitos de la 
API antes de escalar el sistema.

A nivel de frontend, se diseñó una primera estructura de interfaz, todavía no 
conectada al backend, cuyo objetivo era definir la interacción básica con el usuario 
y anticipar las necesidades de visualización del mapa y los resultados.

RESULTADO TÉCNICO
Sistema preparado para consumir APIs externas, con una estructura inicial clara y 
validada para continuar el desarrollo.
