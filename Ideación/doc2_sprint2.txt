DESCARGA DE DATOS Y PRIMERAS ESTRUCTURAS PERSISTENTES
Durante este sprint se implementó la capacidad de descarga de datos reales. 
Se desarrollaron scripts específicos para la obtención de datos de radiación 
y de imágenes geográficas, destacando descargar_radiacion.py y 
peticion_imagen_PNOA.py. En esta fase se decidió utilizar PNOA para las 
imágenes debido a las limitaciones de Copernicus en el nivel de zoom necesario 
para detectar tejados.

Se completó la descarga de todos los datos correspondientes a Villaviciosa, 
garantizando la cobertura total del área de estudio. Esto implicó gestionar 
volúmenes elevados de datos y organizar su almacenamiento en el sistema de archivos.

Paralelamente, se inició el diseño de la base de datos. El script db_config.py 
se utilizó para definir la estructura inicial, crear tablas y preparar el entorno 
para la futura carga de datos procesados.

La interfaz continuó evolucionando para adaptarse a la disponibilidad de datos 
reales, aunque todavía sin integración completa con el backend.

RESULTADO TÉCNICO
Sistema capaz de descargar datos reales de forma controlada, con una base 
de datos inicial definida y lista para ser poblada.
